# Documentation checks

Run these commands from the repository root using the documentation environment
with this checkout available as `Cropbox`.

## Normal documentation build

```sh
julia --project=docs docs/make.jl
```

This is the build used by the existing documentation action on pull requests.
Documenter executes `@example` blocks and checks cross-references. After the
build, `navigation.jl` checks the page list, local images, and unused source
assets before deployment. Images written by examples are checked in the fresh
`docs/build` directory; they do not need a placeholder in `docs/src`.

For a quick source-only check without package dependencies:

```sh
julia docs/checks/navigation.jl
```

If a page references an image generated by an example, use the full build.
`julia docs/checks/navigation.jl --built` can recheck its output, but does not
rebuild it. Do not use a stale build to validate changed source files.

## Additional local checks

These checks are **local-only**, not extra GitHub Actions steps. Run both when
changing learning pages, example names, shared setup, or their expected results:

```sh
julia --project=docs docs/checks/learning.jl
julia --project=docs docs/checks/examples.jl
```

- `learning.jl` executes selected pages and checks numerical results. Update its
  page list and assertions when the corresponding examples change.
- `examples.jl` builds a temporary copy with `# hide` lines removed from
  `@example` blocks. This catches examples that depend on invisible setup.
  Ordinary `julia` fences may be syntax fragments and are not executed.

Keep these results separate from the PR's documentation CI status. The local
checks do not replace a full build against the current base branch.
