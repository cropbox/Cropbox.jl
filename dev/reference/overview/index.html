How to Use the Reference

These pages describe Cropbox in detail. Use them to answer a specific question while writing or inspecting a model; they are not a sequence of lessons. For a guided introduction, start with the Quick Start and the Learning Path.

The Public API Index provides an alphabetical docstring index as well as a task-oriented list of exported names.

Read an example with its contract

Reference entries include argument combinations, options, executable examples, their output, and the conditions needed to interpret them correctly. For example, the visualization reference pairs graphical results with expandable terminal output rather than asking you to infer a plot from its call signature.

Code blocks in the same page can share setup. Run them in page order when an example refers to a model or table defined earlier. A signature containing options... is a description of the call, not a complete runnable example.
